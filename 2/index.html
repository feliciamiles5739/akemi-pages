Akemi — get the pages into Google

What this is: we have 42 Akemi pages live on Amazon (an Amazon S3 web address). Google knows they exist but hasn't added most of them to search yet. Your job: ask Google to crawl them, then watch them get added.

This is only about those Amazon pages — it has nothing to do with any other Akemi website. Everything you do is inside Google Search Console.

Work top to bottom. Step 3 does the real work. Steps 1–2 take two minutes, Step 4 you repeat every day or two until the number stops climbing. Each blue button copies the exact text you need — don't type these by hand.

1 Open Search Console & pick the right property

This is Google's dashboard for the pages.

  • Open Search Console (button below), sign in as alice3861wil@gmail.com.
  • Top-left, click the property dropdown and choose the one that starts with akemicoffeeboost.s3 (second button is the exact address).

2 Check the sitemap is there

The sitemap is the list of all 42 pages. It was already submitted — you're just confirming.

  • Left menu → Sitemaps.
  • You should see one row with status Success. If you see it — do nothing, go to Step 3.
  • Only if it's missing: paste the text below into the "Add a new sitemap" box and click Submit.
akemi-coffee-boost/sitemap.xml

3 Ask Google to crawl every page (the tool)

This is the part that actually gets them crawled. Our tool clicks through all 42 for you.

  • Open the tool page (first button) and do its one-time install the first time only — it follows its own on-screen steps.
  • Keep Search Console open in one browser tab, the priority list (second button) in another.
  • Start it and leave it running — it types each page into Google's Inspect box and clicks Request Indexing on its own.
https://gsc-auto-index.misc-e60a.workers.dev/
https://gsc-auto-index.misc-e60a.workers.dev/priority/

If it says "quota exceeded": that's normal — Google limits how many per day. Stop, and run it again tomorrow until the list is finished.

4 Watch them get added (every 1–2 days)

Checking progress — repeat until the number stops rising.

  • Left menu → Pages (under "Indexing"). Watch the Indexed number go up toward 42.
  • To check one page: paste its address in the top Inspect box — "URL is on Google" means it's in.
  • Don't expect it all on day one. Some pages show in a few days, most within 2–4 weeks. Keep running Step 3 each day until the whole list is requested.

The whole priority list has been requested, and the Pages → Indexed count has climbed and leveled off. Send Bob that number (e.g. "34 of 42 indexed"). That's the whole job.
