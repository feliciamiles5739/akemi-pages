Akemi — get the pages into Google

What this is: we have 42 Akemi pages live on an Amazon web address. Google knows they exist but hasn't added most of them to search yet. Your job: ask Google to crawl them, then watch them get added.

This is only about those Amazon pages — nothing to do with any other Akemi website. Everything you do is inside Google Search Console.

Work top to bottom. Step 3 is the real work and you'll repeat it over a few days. Every blue button copies the exact text you need — don't type these by hand.

1 Open Search Console & pick the right property

Search Console is Google's dashboard for these pages.

  • Open Search Console (button below) and sign in as alice3861wil@gmail.com.
  • Top-left, click the property dropdown and choose the one that starts with akemicoffeeboost.s3 (second button is the exact one).
https://search.google.com/search-console
https://akemicoffeeboost.s3.us-east-1.amazonaws.com/

2 Check the page list (sitemap) is there

The "sitemap" is just Google's list of all 42 pages. It was already added — you're only confirming it.

  • Left menu → Sitemaps.
  • You should see one row with status Success. If it's there — do nothing, go to Step 3.
  • Only if the list is empty: paste the full address below into the "Add a new sitemap" box and click Submit. (This address also opens in a browser, so you can click it to check it works.)
https://akemicoffeeboost.s3.us-east-1.amazonaws.com/akemi-coffee-boost/sitemap.xml

3 Ask Google to crawl each page

You do this one page at a time, right inside Search Console. No other tool needed.

  • Open the page list (button below) in another tab — it has all 42 links, each with its own Copy button.
  • In Search Console, click the long bar at the very top that says "Inspect any URL".
  • Paste one page address, press Enter, wait a few seconds, then click "Request Indexing".
  • Repeat for the next page. Work down the whole list.
https://feliciamiles5739.github.io/akemi-pages/

If it says "quota exceeded" or "you've reached your limit": that's normal — Google only allows so many per day. Stop there and carry on tomorrow until all 42 are done.

4 Watch them get added (every 1–2 days)

Checking progress — repeat until the number stops rising.

  • Left menu → Pages (under "Indexing"). Watch the Indexed number climb toward 42.
  • To check one page: paste its address in the top "Inspect any URL" bar — "URL is on Google" means it's in.
  • Don't expect it all on day one. Some show in a few days, most within 2–4 weeks. Keep doing Step 3 each day until every page has been requested.

✓ When you're finished

All 42 pages have been requested (Step 3), and the Pages → Indexed count has climbed and leveled off. Send Bob that number (e.g. "34 of 42 indexed"). That's the whole job.
